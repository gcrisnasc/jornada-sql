## 📖 Sobre

Este repositório é o diário da minha jornada de estudos em SQL e PostgreSQL. O curso que estou fazendo tem foco em **pesquisa e aprendizado com apoio de Inteligência Artificial**, e por isso uso a IA como ferramenta para pesquisar, tirar dúvidas, gerar cenários de prática e simular entrevistas.

**Meu objetivo:** adquirir conhecimento sólido em SQL e ganhar autonomia para resolver problemas reais com dados. Busco a evolução constante, e este repositório é o registro dela, com erros e acertos.
